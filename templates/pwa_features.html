📖 Flujo de Notificaciones Push en PWA

1️⃣ Permiso del Usuario

El navegador solicita al usuario autorización explícita para recibir notificaciones mediante Notification.requestPermission().

2️⃣ Registro del SW

Se registra un Service Worker que actúa como intermediario entre el servidor push y el navegador, incluso cuando la app está cerrada.

3️⃣ Suscripción VAPID

El SW suscribe al navegador usando claves VAPID. El endpoint único se envía al servidor para identificar al dispositivo.

4️⃣ Servidor envía Push

El servidor usa la biblioteca pywebpush para cifrar y enviar mensajes al Push Service del navegador (FCM, APNS, etc.).

5️⃣ SW muestra notificación

El Service Worker intercepta el evento push y llama a showNotification() para mostrar la alerta al usuario.

6️⃣ Interacción

Al hacer click, el evento notificationclick del SW puede abrir la app, navegar a una URL específica o ejecutar acciones.
